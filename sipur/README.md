# ג'דיי של סיפור קצר — תרגול מאפייני הסיפור הקצר

אפליקציית לימוד ותרגול בעברית (מימין לשמאל) לקראת הערכה בספרות: אקספוזיציה, סיבוך / קונפליקט, נקודת שיא, התרה, סיום פתוח / סגור, דמויות ראשיות ומשניות.
עם סיפורי תרגול מומצאים בהשראת מלחמת הכוכבים (לא סצנות מהסרטים) וגם סיפורים רגילים.

## איך פותחים
- **הכי פשוט:** לחיצה כפולה על `sipur/index.html` — נפתח בדפדפן ועובד בלי אינטרנט.
- **בטלפון:** אחרי פרסום ב-GitHub Pages — `https://ajrcre.github.io/jukim/sipur/`.
- **שרת מקומי (לא חובה):** `python3 -m http.server 8000` מתיקיית הריפו, ואז `http://localhost:8000/sipur/`.

## מה יש
- **לימוד** — לכל מושג: הסבר קצר, דוגמה, והבחנה ממושג קרוב (שיא ↔ התרה, התרה ↔ סיום סגור ועוד), ומפת עלילה.
- **תרגול** — סבבים של 10 שאלות (58 שאלות במאגר): בחירה, זיהוי פסקה בסיפור, התאמה, סידור ומיון. רמז לפני תשובה, משוב והסבר אחרי, תוצאות לפי מושג, תרגול ממוקד וחזרה על טעויות. התאמה וסידור עובדים בהקשה וגם בגרירה.
- **מבחן תרגול** — 12 שאלות בלי רמזים ובלי משוב עד ההגשה; אחר כך ציון, תוצאות לפי מושג והטעויות עם הסברים. הציון נשמר בנפרד מהתרגול.

## פרטיות
אין הרשמה, תשלום, מפתח API או שירות חיצוני. שום פרט או תשובה לא נשלחים לשום מקום; ההתקדמות נשמרת רק ב-localStorage של הדפדפן, ויש כפתור איפוס במסך „על האפליקציה”.

ההסברים הם הסברים מקובלים ברמת מבוא, ולא בהכרח זהים לניסוח במחברת הכיתה. אפליקציה לא רשמית, ללא קשר ל-Lucasfilm או Disney.

## מבנה ובדיקות
Vanilla JS בלי build (סקריפטים רגילים, כדי שיעבוד גם מ-`file://`):
`js/content.js` (תוכן), `js/engine.js` (Strategy לבדיקת תשובות, Repository להתקדמות, Builder לסבבים, מודל ללוח ההתאמה), `js/ui.js` (נתב ומסכים), `js/app.js`.

```bash
node --test tests/js/*.test.mjs        # שלמות התוכן ולוגיקה (רץ גם ב-CI)
node tests/e2e/sipur.e2e.mjs           # דפדפן אמיתי, טלפון ומחשב (דורש Playwright)
```
