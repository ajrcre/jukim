# jukim — מחץ את הג'וק 🪳

משחק דפדפן (מחשב וטלפון): ג'וקים ריאליסטיים עם רגליים זזות נכנסים מקצוות המסך — צריך למחוץ אותם לפני שנגמר הזמן.

## איך משחקים
- **עכבר / מגע** — קליק או נגיעה על הג'וק.
- **מצלמה קדמית** — יד פתוחה מעל ג'וק שנסגרת לאגרוף ✋➜✊ (זיהוי ידיים עם MediaPipe, רץ מקומית בדפדפן).
- **מצלמה אחורית** — הצילום החי משמש כרקע, והג'וקים רצים על הרצפה האמיתית שלך.
- רקעים: אריחים (ברירת מחדל), פרקט, טראצו, מטבח שחמט, בטון, או תמונה משלך.

שלבים עם טיימר ויעד מחיצות, קומבו, שיא אישי, ג'וק זהב נדיר (50 נק'), כתמים ושאריות שנשארים על הרצפה, ג'וקים שבורחים מהאצבע/סמן, נעצרים פתאום ומזיזים מחושים. צלילי מחיצה וריצה נוצרו עם ElevenLabs. ניתן להתקין כאפליקציה (PWA).

## הרצה מקומית
```bash
python3 -m http.server 8000   # http://localhost:8000
```
המצלמה עובדת רק ב-HTTPS או ב-localhost.

## פרסום
ה-workflow ב-`.github/workflows/pages.yml` מריץ בדיקות ומפרסם ל-GitHub Pages על כל push ל-`main`.
פעם אחת: Settings → Pages → Source: **GitHub Actions**.

## צלילים
```bash
ELEVENLABS_API_KEY=... python3 tools/generate_sounds.py [--force] [--only squash1]
```
הקבצים נשמרים ב-`assets/sounds` ונכנסים לריפו — המפתח לא מגיע לדפדפן.

## בדיקות
```bash
node --test tests/js/*.test.mjs
python3 -m pytest tests
```

## מבנה
Vanilla JS (ES modules, ללא build). תבניות: State (מצבי משחק), Strategy (רקעים, קלט), Factory (סוגי ג'וקים), Observer (EventBus), Facade (`Game`).
