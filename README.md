# jukim — מחץ את הג'וק 🪳

משחק דפדפן (מחשב וטלפון): ג'וקים ריאליסטיים עם רגליים זזות נכנסים מקצוות המסך — צריך למחוץ אותם לפני שנגמר הזמן.

## איך משחקים
מסך פתיחה מצויר ← מסך אפשרויות (הכול גלוי לפני המשחק) ← משחק. מוחצים בקליק או בנגיעה.
- **קלאסי** — ג'וקים נכנסים מקצוות המסך.
- **ג'וקים מהפה 😮** — מצלמה קדמית: כשמישהו במצלמה פותח את הפה, ג'וקים זוחלים לו החוצה מהפה (זיהוי פנים עם MediaPipe FaceLandmarker, עד 4 פנים, רץ מקומית בדפדפן).
- **רקע** — אריחים (ברירת מחדל), פרקט, טראצו, מטבח שחמט, בטון, תמונה משלך, או 📷 מצלמה אחורית כרקע חי.

שלבים עם טיימר ויעד מחיצות, קומבו, שיא אישי, ג'וק זהב נדיר (50 נק'), כתמים ושאריות שנשארים על הרצפה, ג'וקים שבורחים מהאצבע/סמן, נעצרים פתאום ומזיזים מחושים. גוף הג'וק מרונדר ב"shader" בתוכנה (מפת גובה, תאורה לכל פיקסל, ברק כיטין, אור קבוע בעולם). הצלילים נוצרו עם ElevenLabs. ניתן להתקין כאפליקציה (PWA).

## הרצה מקומית
```bash
python3 -m http.server 8000   # http://localhost:8000
```
המצלמה עובדת רק ב-HTTPS או ב-localhost.

## פרסום
ה-workflow ב-`.github/workflows/pages.yml` מריץ בדיקות ומפרסם ל-GitHub Pages על כל push ל-`main`.
פעם אחת: Settings → Pages → Source: **GitHub Actions**.

## צלילים
```bash
ELEVENLABS_API_KEY=... python3 tools/generate_sounds.py [--force] [--only squash1]
```
הקבצים נשמרים ב-`assets/sounds` ונכנסים לריפו — המפתח לא מגיע לדפדפן.

## בדיקות
```bash
node --test tests/js/*.test.mjs
python3 -m pytest tests
```

## מבנה
Vanilla JS (ES modules, ללא build). תבניות: State (מצבי משחק), Strategy (רקעים, מקור הג'וקים: `EdgeSpawner`/`MouthSpawner`), Factory (סוגי ג'וקים), Observer (EventBus), Facade (`Game`).
